# Douyin Favorites to Obsidian KB

> 发布前审核稿：核心目标是定时抓取抖音收藏 → 转写/OCR → AI 总结分类 → Obsidian 同步。此包目前提供技能流程和本地知识库工具，完整采集适配器尚未交付。不能作为开箱即用自动抓取器发布。

把抖音、TikTok 来源资料、书籍和个人思考积累为可检索、可追溯的 Obsidian 个人知识库。

抖音与 TikTok 均可导入用户提供的转写或已整理资料。平台登录、自动采集和媒体转写需要单独配置外部工具；仓库没有内置这两个平台的自动采集器。

这是一个 **Codex Skill + 独立本地工具包**。技能指导宿主代理提取、整理和引用资料；工具负责笔记落盘、分类入口、跨库搜索、去重、删除保护，以及新增同步与历史补录的区分。

| 来源 ID 去重、完整基线、只同步新增、历史补录 | 已实现、自动测试 |
| 用户删除笔记后不自动重建 | 已实现、自动测试 |
| Windows 每日任务设置 | 已实现、语法检查；需要外部适配器和完整基线 |
| 抖音登录、媒体下载、ASR/OCR、云端 AI 调用 | 外部能力，未随仓库提供 |

**安装 Skill 不会自动安装整个抖音处理环境，也不意味着每天同步已经开启。** 无抖音适配器时，仍可让代理整理提供的视频转写、图文 OCR、书籍摘录，再导入笔记。此仓库不是“开箱即用的抖音自动抓取器”。

## 完整版本的使用流程与分工

以下是完整自动化版本的交付目标，**不是当前审核包已经具备的能力**。当前包缺少采集、转写和 AI 调用适配器，不能按此流程直接完成自动部署。

| 步骤 | 用户手动完成 | Skill 与配套程序负责 |
| --- | --- | --- |
| 首次安装 | 安装 Skill，发出配置请求 | 检查环境、安装依赖、生成配置并报告结果 |
| 连接 Obsidian | 选择或创建笔记库，提供文件夹路径 | 验证路径，建立笔记目录和主题导航 |
| 登录抖音 | 在浏览器中扫码登录 | 保存本地登录状态，检查收藏读取能力 |
| 连接 AI | 选择整理服务，完成账户登录或配置凭据 | 检查连接，调用 AI 总结与分类 |
| 选择范围 | 设置发布日期、是否补录历史、每日处理上限 | 在下载和 AI 整理前筛选，保存运行状态 |
| 设置时间 | 选择每日运行时间，例如 20:00 | 建立定时任务，避免任务重叠 |
| 日常运行 | 保持电脑、网络及必要代理可用 | 获取新增收藏，视频转写、图文识别、生成笔记、分类并同步 |
| 异常处理 | 登录失效时重新登录，额度不足时处理账户问题 | 记录失败原因，保留可重试状态，跳过已完成内容 |

Skill 提供操作说明和工作流程；每天实际执行的是配套程序和系统定时任务。安装 Skill 本身不会开启每日同步，也不能保证电脑关机、休眠或断网时执行。

每日新增同步与历史补录应分别控制：暂停历史补录不影响每日新收藏同步。启用只同步新增之前，需建立已有收藏的完整 ID 基线；该步骤只读取元数据，不整理全部历史内容。完成状态用于去重和中断续跑，失败项目应单独记录并按重试策略处理。

完整版本应让代理完成环境配置和任务设置，用户无需反复复制代码。**当前审核包的实际操作见下文：需要外部适配器，尚未实现上述一键部署。**

## 安装 Skill

把整个仓库文件夹放入 Codex 技能目录，并命名为 `douyin-favorites-obsidian-kb`。例如 Windows 的 `%USERPROFILE%\.codex\skills\douyin-favorites-obsidian-kb`。重新加载技能后使用：

> 使用 $douyin-favorites-obsidian-kb 整理我提供的资料，保存到我指定的 Obsidian 库。只同步新增，先暂停历史补录。

## 本地工具快速开始

需要 Python 3.10+；本工具不需要 pip 安装依赖。复制配置并填写路径：

```powershell
Copy-Item config.example.json config.local.json
```

先让宿主代理根据 [输入契约](references/input.md) 生成 `prepared-notes.json`。导入用户明确选择的历史资料：

```powershell
python scripts/kb.py --config config.local.json import --mode backfill --input prepared-notes.json
python scripts/kb.py --config config.local.json search "我的问题关键词"
python scripts/kb.py --config config.local.json status
```

想先体验效果，可把输入换成仓库自带的 `examples/notes.example.json`。默认示例配置会创建独立的 `my-vault`，不会改动已有知识库。

要筛选抖音发布日期，例如从某日开始，配置 `publication_since` 为包含时区的 ISO 时间，如 `2026-06-01T00:00:00+08:00`；这只是示例，不是默认限制。视频和图文均由输入的 kind 字段区分，不排除图文。

只处理未来新增收藏时，先读取完整 ID 快照并建立基线，再启用新增同步。详见 [同步与部署](references/sync.md)。不要把试扫 50 条当作全部基线。每天自动运行需要自行配置一个符合契约的外部适配器；本工具不会为跳过的旧收藏调用云端 AI。

## 目录效果

```text
你的库/
  外源资料/
    _主题导航.md
    分类/AI 与技术.md
    分类/心理与成长.md
    笔记/主题标题-稳定标识.md
    assets/稳定标识/001.webp
```

每篇笔记回链分类节点，不必等所有资料处理完才分类。图谱显示由 Obsidian 自己控制。原有笔记不会自动迁移或被重新整理；需要用户明确选择后另做迁移。

## 发布与隐私

仓库代码为独立实现。**不包含、不再分发、不改写**其他抖音项目的源码、模型或安装包。第三方工具由用户根据其许可证独立获得。本仓库 MIT 许可只涵盖这里的原创文件，不授予任何第三方代码、视频、书籍或模型的再分发权限。

不要上传自己的知识库、登录态、Cookie、API Key、收藏清单、运行日志和本地配置。分享整理方法与代码，不上传原视频、整本书或他人的内容。

已知限制：采集器可能受平台变化影响；403 的确切原因需刷新地址和查看页面才能判断；未验证的上游内存和下载问题不会被这个技能自动修好。模型读取资料不会形成永久训练记忆，回答仍需实际检索文件。
