# 笔记内容规范

每条包含一句话摘要、实质观点、原资料支持的方法/例子/数字、必要的不确定性、分类和来源。无可执行方法时不用硬凑。作者关于效果的宣传不升级为事实。整理补充明确标注，但不在每段重复免责声明。

视频保留原始转写；图文按图片顺序保存 OCR 文字和本地图片，OCR 不包含未识别的视觉信息。英文名、数字和工具链接不能由不清晰转写猜测。没有有效文字的纯图片应待人工/视觉工具确认，而非从标题编造正文。

书籍按章节和页码记录。页码以输入文件为准，并注明 PDF 页码与印刷页码差别。笔记链接可以表达概念联系，但不能为了“知识图谱漂亮”制造不存在的因果联系。

来源、作者、时间、类型和主题写进 YAML 属性。正文按知识主题组织。原始材料折叠显示，阅读正文无需重新理解整段逐字稿。最终问答引用笔记路径，重要断言进一步回到原视频或书籍章节。
